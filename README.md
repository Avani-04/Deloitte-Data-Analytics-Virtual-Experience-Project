# Deloitte-Data-Analytics-Virtual-Experience-Project

 - Developed interactive dashboards and visual reports to analyse machine downtime and identify the company experiencing the highest operational downtime. 
 - Performed data analysis on equipment performance datasets to identified high-downtime machines through dashboard analysis, improving operational visibility and reporting efficiency. 
 - Analysed employee compensation datasets using Microsoft Excel to classify equality scores and evaluate gender pay gap categories. 
 - Utilized Tableau and Excel to transform raw datasets into meaningful dashboards and analytical reports.
